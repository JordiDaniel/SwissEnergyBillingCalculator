# ZEV Ebix Web (Home Assistant Add-on)

Dieses Add-on startet die ZEV-Weboberfläche direkt in Home Assistant (Ingress).

## Features
- CSV/XML Import aus lokalem Pfad oder Dropbox-Link
- ZEV Monatsauswertung inkl. Bezug/Rücklieferung
- Konfigurierbare Zähler-/Preiszuordnung

## Datenpersistenz
Die Konfiguration wird in `/data/zev-config-web.json` gespeichert.

## Installation
1. In Home Assistant: **Einstellungen > Add-ons > Add-on Store > Repositories**.
2. Repository-URL hinzufügen.
3. Add-on **ZEV Ebix Web** installieren und starten.
4. Über Ingress öffnen.
